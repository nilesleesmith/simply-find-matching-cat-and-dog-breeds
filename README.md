# Cat and Dog Breed Matcher

A JavaScript project that compares cat and dog breeds using temperament information from two animal APIs.

## About

This project allows a user to search for either a cat breed or a dog breed.

The selected breed is retrieved from its API and compared with breeds from the other animal type.

The program compares temperament characteristics and returns the breed with the highest number of matching traits.

## Features

- Search for a cat or dog breed
- Retrieve breed information
- Display details about the searched breed
- Retrieve breeds from the opposite animal type
- Compare temperament characteristics
- Calculate a match score
- Display the breed with the strongest temperament match
- Show matching temperament traits

## Running the Project

1. Clone or download the repository.
2. Add valid API keys for The Cat API and The Dog API.
3. Open `index.html`.
4. Select whether to search for a cat or dog.
5. Enter a breed name.
6. Select the search button.
7. Review the searched breed and matching breed.
8. Open the browser developer tools and select the Console to view logged data.

## Purpose

This project was created while practicing JavaScript APIs, arrays, nested loops, comparison logic, functions, and DOM manipulation.

The focus is on combining information from two APIs and using JavaScript logic to calculate a new result instead of only displaying API data.
